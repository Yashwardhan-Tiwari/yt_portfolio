YASHWARDHAN TIWARI — DEVELOPER PORTFOLIO

IMPORTANT: EXTRACT THE ZIP BEFORE OPENING THE WEBSITE.

1. Right-click Yashwardhan-Developer-Portfolio-FIXED.zip.
2. Choose “Extract All…” (Windows) and extract it into a normal folder.
3. Open the extracted folder.
4. Double-click index.html.

Keep the css, js and assets folders next to index.html. Do not move individual
HTML files out of this folder. The website uses relative paths so it can also
be hosted on GitHub Pages or regular static web hosting.

If you use VS Code:
- Open the extracted folder in VS Code.
- Start Live Server from index.html.

If an old copy is already open, close it and use this newly extracted copy.
