# Yashwardhan Tiwari — Single-file Developer Portfolio

This version fixes navigation by putting all eight views into one `index.html`. Menu links switch views using in-page hash routes (`#home`, `#about`, `#projects`, `#internships`, `#skills`, `#journey`, `#notes`, `#contact`). They do not depend on opening another HTML file.

## Open it
1. Extract the ZIP with **Extract All**.
2. Open `index.html` in Chrome/Edge, OR double-click `OPEN-PORTFOLIO.bat` on Windows.
3. Use the top navigation. All sections are in the same page, so navigation works even from a local `file:///` address.

The other HTML files are compatibility shortcuts that redirect to the matching view in `index.html`. They are not separate page implementations.

## Included
- All eight portfolio sections: Home, About, Projects, Internships, Skills & Lab, Journey, Dev Notes, Contact.
- Embedded photo sources plus original `assets/images/` files.
- Theme toggle, mobile menu, portfolio interactions, project modals, notes drawer, sorting/bitwise demos, and cinematic animations.
- Resume PDF and editable CSS/JS source in `css/` and `js/`.

## Note
External links (GitHub and the pitch deck) require an internet connection. Email buttons open the visitor's configured email app. The contact form prepares an email; it does not send to a backend.
